# FLask Products-Shop/E-commerce
Server-side Full Stack E-commerce Application

This is a fully functional server-side e-commerce application built with Flask. It incorporates a wide range of features typically found in real-world e-commerce platforms:

    Google Authentication: Users can sign in using their Google accounts.

    Admin Functionality: Admin users can manage products, users, and view detailed data.

    Multilingual Support: The application supports both Georgian and English languages for a diverse user base.

    Secure Authentication: Users can securely register and log in with Flask-Login and Flask-WTF.

    Email Verification: Users must verify their email addresses for added security.

    Stripe Payments: Integrated Stripe payment gateway for secure product purchases.

    Rate Limiting: Protection against abuse and misuse of the system through rate limiting.

    Flask Admin: Easy-to-use admin interface for managing products, users, and other resources.

    Mailing & Security: Enhanced security features using Flask-Mail and security libraries.
